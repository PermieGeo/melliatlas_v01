# Source Ingestion Module Contract

**Owner:** `apps/api/src/modules/sources/`. **Status:** internal schemas, URL-policy preflight, and operator-configurable inert provider request settings. Ingestion is not running.

- **Responsibility:** Define source-ingestion metadata and enforce operator-reviewed destination allowlists before any future network access.
- **Public entry points:** [providerConfiguration.ts](providerConfiguration.ts) exports `ProviderConfigurationRepository` and the pure `buildProviderRequest` helper; the builder has no network access. [contracts.ts](contracts.ts) exports source, fetch policy, document, run and notice candidate schemas/types; [destinationPolicy.ts](destinationPolicy.ts) exports `evaluateSourceDestination`; [municipalSourceRegistry.ts](municipalSourceRegistry.ts) exports the internal, read-only `ApprovedSourceRegistry.getApproved(id)` (with a municipal compatibility alias) and immutable registration revision; [httpFetcher.ts](httpFetcher.ts) exports `RestrictedSourceFetcher`, `directHttpsTransport` and injectable DNS/transport boundaries.
- **Owned data:** Municipal source access policy and extraction contracts; approved municipal registrations read from `source_catalog`, whose physical schema belongs to [database infrastructure](../../db/contract.md). `source_catalog_versions` stores append-only registration snapshots. The `treatment-feed` source requires explicit reviewed approval; configuration edits revoke approvals. No source documents or notices are written. Provider candidate endpoint and request parameters are stored in `source_catalog.api_request_config`, separate from the public landing-page URL; operator updates use optimistic revision checks.
- **Allowed dependencies:** Zod, Node's HTTPS/DNS/TLS modules and the injected PostgreSQL pool for registry reads. URL policy itself has no network or database access.
- **Forbidden:** Arbitrary URL fetching, implicit approval of publicly visible sites, unchecked redirects, synthetic notices, or exposing operator review details through public API routes.
- **Invariants:** Fetch eligibility requires an enabled source, explicit access review with evidence, exact-match HTTPS DNS host and approved path prefix. `/notices` admits `/notices/2026` but not `/notices-private`. IP literals, URL credentials, fragments and encoded traversal/separators fail closed. Current notice candidates are restricted to `text_only` until geometry normalization exists; verified candidates need evidence excerpts.
- **Provider boundary:** Candidate provider settings can be edited only with a server-side operator bearer token. `collectionEnabled` is always false in the current slice. The database still forbids approving `treatment` source kinds under migration 002; do not treat the saved candidate as authorized or add a fetch call without additive migration and reviewed permission.
- **Transport security:** `RestrictedSourceFetcher` requires reviewed source metadata, blocks private/special-use DNS answers, pins the validated address to a direct TLS connection with certificate validation, verifies the connected IP, revalidates each redirect and enforces body/MIME/encoding, timeout, concurrency and retry limits. No proxy or automatic decompression is used. It is not connected to a job, API route or public notice layer.
- **Extension:** Add reviewed treatment-source approval and restricted adapters, restricted HTTP transport and durable ingestion repositories. `getApproved` has no HTTP route and does not trigger collection. Spatial claims require independent geometry validation. Public wire schemas belong to `packages/contracts` once endpoints exist.

- **Reference parser:** [beekeeperPlanPage.ts](beekeeperPlanPage.ts) parses one observed JSON page shape without network access, inferred values or publication authority. Different providers may require independent adapters; request configuration alone does not imply compatible responses.
- **Compatibility:** Migration 004 promotes the legacy configuration to an inert `treatment-feed` source while preserving the prior row's immutable history. No source is approved by this migration.
